# Memento

**Keep the words that matter.**

Memento is a mobile-first creator for beautiful, shareable digital wishes, personal messages, apologies and notices—each intended to be shared through a unique link.

## Foundation
- React + TypeScript + Vite
- Mobile-first interface
- Light/dark theme toggle
- Four creation categories
- Editor and preview foundation
- GitHub Pages workflow

> The current preview stores pages locally and is not yet cloud-shareable. Firebase-backed pages, secure access and actual unique recipient links are upcoming.

## Development
`npm install` then `npm run dev`. Build with `npm run build`.

## Deploy
Enable GitHub Pages with GitHub Actions. The included workflow builds and deploys the Vite site.
